# DailyPulse – Namaz, Hydration & Sleep Tracker

DailyPulse is a modern, native iOS app built in Swift & SwiftUI designed to help users maintain daily spiritual discipline, healthy hydration, and restorative sleep habits with real-time cloud synchronization.

## 🚀 Running on Mac with Xcode
1. Open `DailyPulse/DailyPulse.xcodeproj` in Xcode on your Mac.
2. Add Firebase packages via **File > Add Package Dependencies**:
   - URL: `https://github.com/firebase/firebase-ios-sdk.git`
   - Select: `FirebaseAuth` and `FirebaseFirestore`.
3. Press **Cmd + R** to run in the iOS Simulator.

For detailed architecture, models, API details, and Firebase configuration, please see the complete documentation in [DailyPulse/README.md](DailyPulse/README.md).
